## 一、这是什么

一个**零依赖、零构建、零追踪**的单文件网页应用。打开即用，不需要服务器、不需要数据库、不收集任何用户信息。

它解决的是一个很具体的问题：一个中国人刚到异国，最先要办的事——吃什么、怎么申请学校、去哪找工作、房子在哪租、钱怎么汇回家、出事找谁——这些信息散落在几十个网站和无数条小红书笔记里。这个页面把它们收进一页，按场景分好类，中英（及其它 8 种语言）随时切换。

页面顶部保留了一行致敬语，写给 2025 年在墨尔本夜色中遇害的华人骑手冯师傅，以及每一位在异国街头奔波的普通谋生者。这个项目的人文出发点来自那里。

## 三、技术实现

**核心事实：整个应用就是一个 HTML 文件。** 没有 `node_modules`，没有打包步骤，没有框架，没有外部 CDN 依赖，没有统计脚本。

| 项 | 选择 | 理由 |
|---|---|---|
| 结构 | 单文件 HTML5 | 复制即用、邮件可发、U 盘可带、离线可开 |
| 样式 | 原生 CSS + CSS 变量 | 三套主题只需换 `body[data-theme]` 上的变量组 |
| 逻辑 | 原生 JavaScript（ES6，无框架） | 无需构建，浏览器直接跑 |
| 国际化 | 自研 i18n 表 `T[lang][key]` + `data-i18n` 属性 | 十种语言各一张文案表，切换时批量回填 `textContent` |
| 数据 | 内联 JS 常量（`CATS` / `FRIENDLY` / `TOP10` / `GOALS`） | 改数据不用碰渲染逻辑 |
| 部署 | GitHub Pages 静态托管 | 免费、HTTPS、全球 CDN，无需运维 |

### 目录结构

## 五、部署到 GitHub Pages

线上地址：`https://ucoingroup.github.io/Earth-Chinese-Navigation/`

1. **仓库根目录必须是 `index.html`**——本项目的源文件名为 `全球华人导航.html`，上传时重命名为 `index.html`（Pages 只把 `index.html` 当作目录首页）。
2. 仓库 **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**。
3. 约 1 分钟后生效。此项目**不需要** GitHub Actions、不需要构建、不需要 `package.json`。
4. 想绑定自定义域名：Pages → Custom domain，并在 DNS 添加 CNAME 指向 `ucoingroup.github.io`。

> ⚠️ 单文件应用的一个小坑：如果页面里出现相对路径资源（目前没有），改名或换目录会失效。当前所有内容内联，因此可任意改名、任意路径部署。

## 六、数据口径与免责

本页面所有数字都是**编辑整理的估算值**，不是官方统计。请按以下口径理解：

| 数据 | 口径 | 注意事项 |
|---|---|---|
| 海外华人规模「约 5000 万」 | 页面文案口径；不同机构估算区间约 5000–6000 万 | 是否计入港澳台、是否计入华裔混血，差异很大 |
| 各城市华人人口（如「多伦多约 70 万」） | 各国人口普查「华裔/Chinese origin」自我认同口径 + 华社公开资料 | 统计年份不一，多为 2021–2024 年数据 |
| 十大语言使用人数 | Ethnologue 等机构对**总使用人数**（母语 + 第二语言）的近年估算 | 阿拉伯语是否合并方言、印尼语/日语是否入榜，不同榜单结论不同 |
| 华人友好榜排名 | 编辑按「华人社区规模 + 华语服务便利度 + 社区口碑」综合排序 | **非官方评级、非投资/移民建议**，仅供了解 |
| 站点简介 | 各平台公开介绍与作者使用体验 | 平台政策、费率、可用性会变，以官网为准 |

**本项目不构成任何投资、移民、法律或消费建议。** 涉及汇款、租房、求职等实际交易，请自行核实对方资质与当地法规。

## 七、如何修改

### 加一个导航站点

在 `CATS` 中对应分类的 `items` 数组里加一项：

```js
{n:"站点名", flag:"地区标签", u:"https://example.com",
 d:{zh:"中文简介", en:"English description"},
 t:["标签1","标签2"]}
```

`t` 数组是卡片底部的标签，`d` 只写 `zh`/`en` 即可，其他语言会回退英文。

### 改某个洲的 TOP10

在 `FRIENDLY` 里找到对应大洲的 `items`，每条为：

```js
{f:"🇸🇬", n:{zh:"城市 · 国家", en:"City, Country"}, w:{zh:"入选理由", en:"Why"}}
```

数组顺序即排名。前三名自动加金色徽章。

### 新增一种界面语言（5 步）

1. `LANGS` 里加一行：`{code:"ja", label:"日本語"}`（RTL 语言加 `rtl:true`）；
2. 复制一份 `T.en` 对象改成新语言，键名保持一致（缺键会回退英文）；
3. `CATS` / `FRIENDLY` 里各分类和洲名的 `name` 对象补上该语言键（缺失会显示 `undefined`，务必补齐）；
4. 顶部语言选择器由 `LANGS` 自动生成，无需改 HTML；
5. `TOP10` 无需改，它是数据展示，不是界面语言。

### 换主题配色

改 `body[data-theme="..."]` 下的 CSS 变量即可，`--accent`、`--bg`、`--card`、`--hero-grad` 是最主要的四个。

## 八、兼容性与已知限制

- 支持所有现代浏览器（Chrome / Edge / Safari / Firefox 近两年版本）；不支持 IE。
- 手机端已做响应式，但**友好榜 60 条在城市名较长的小屏上会换行较多**，可后续改为折叠式。
- 深层内容（28 个站点简介、60 条城市理由）目前只有`华语 + English`，其他 8 种语言回退英文显示——这是有意为之，避免低质量机翻；如需补齐，按第七节方式扩展 `d` / `w` 对象即可。
- 页面无后端、无搜索、无收藏功能；所有筛选靠浏览器原生查找（Ctrl+F）。
- 数据更新需手动改文件并提交，没有 CMS。
